# Agents

Structural index of files and folders in this KB. Routing intelligence lives in Sig — this file contains structural facts only.

## T1 — Org-wide flat files (repo root)

- `intent.md` — org mission and high-level goals
- `constraints.md` — org-wide rules, compliance requirements, hard limits
- `decisions.md` — cross-team decisions and rationale
- `agents.md` — this file; structural index

T1 content always goes in one of these four files. There are no T1 subfolders. Do not create `intent/`, `constraints/`, or `decisions/` as directories.
